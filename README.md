# React Native Fundamentals Course Project

## Overview
This repository contains my work from the **React Native Fundamentals** course on Frontend Masters taught by **Kadi Kraman**. It’s an Expo + TypeScript app used to practice core React Native concepts such as navigation, state management, styling, and device features.

## What’s Included
- Expo Router navigation examples
- Counter flow with history
- Shopping list UI components
- Date handling utilities
- Local storage helpers
- Push notification registration helper

## Course Context
This project is the result of completing the React Native Fundamentals course.  The app serves as a learning sandbox rather than a production product.

## Tech Stack
- React Native
- Expo
- TypeScript
- Expo Router
- ESLint + Prettier

## Project Structure
- `app/` – Route-based screens and layouts
- `components/` – Shared UI components
- `utils/` – App utilities (storage, notifications)
- `docs/` – Course notes and specifications

## Getting Started
From the project root:

```zsh
npm install
npm run start
```

## Linting
Linting is wired to run fast on staged files using Husky + lint-staged.

```zsh
npm run lint
```
